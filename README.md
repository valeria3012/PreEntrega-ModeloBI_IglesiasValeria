# BIO-QUIM | Dashboard Ejecutivo en Excel

## Pre-entrega — Capa de visualización final del dashboard

Proyecto desarrollado para el curso de **Data Analytics de Coderhouse**.

El objetivo de esta pre-entrega es presentar la capa final de visualización, interactividad y storytelling de un Sistema de Inteligencia de Negocios en Excel aplicado a BIO-QUIM, empresa ficticia utilizada como caso de análisis.

---

## Archivos de la entrega

### `PreEntrega_ModeloBI_IglesiasValeria.xlsx`
Archivo principal del proyecto.

Contiene la hoja **Dashboard Final**, con:
- KPIs ejecutivos.
- Segmentadores interactivos.
- Visualización mensual de ventas.
- Gráfico de dispersión.
- Capa narrativa dinámica.
- Insights ejecutivos y validación del análisis.

### `Registro_Prompts_IA_BIOQUIM_Valeria_Iglesias.docx`
Documento que registra el uso de **ChatGPT como auditor cognitivo**.

Incluye:
- análisis humano inicial;
- conclusiones obtenidas a partir del dashboard;
- prompt de revisión mediante el enfoque de “abogado del diablo”;
- identificación de posibles sesgos, variables omitidas y explicaciones alternativas;
- refinamientos aplicados al dashboard a partir de la revisión.

---

## Cómo revisar la entrega

> Se recomienda abrir el archivo `.xlsx` con **Microsoft Excel de escritorio** para conservar correctamente el Modelo de Datos, las tablas dinámicas y los segmentadores.

1. Abrir `PreEntrega_ModeloBI_IglesiasValeria.xlsx`.
2. Ir a la hoja **Dashboard Final**.
3. Utilizar los segmentadores:
   - Categoria
   - Region_Maestra
   - Mes
4. Verificar que las visualizaciones respondan a los filtros.
5. Observar el cambio del KPI **Ventas Totales**.
6. Observar el cambio del título narrativo del gráfico mensual al aplicar filtros.
7. Revisar el gráfico de dispersión de volumen vendido y ventas.
8. Abrir `Registro_Prompts_IA_BIOQUIM_Valeria_Iglesias.docx` para consultar el proceso de validación asistida por IA.

## Prueba de interactividad

Para verificar el funcionamiento del dashboard:

1. Seleccionar un valor en **Categoria** y comprobar la actualización de las visualizaciones.
2. Limpiar el filtro.
3. Seleccionar una **Region_Maestra** y comprobar nuevamente los cambios.
4. Limpiar el filtro.
5. Seleccionar un único **Mes**.
6. Verificar que:
   - el KPI de Ventas Totales cambie;
   - el gráfico mensual responda al filtro;
   - el título narrativo muestre el total correspondiente al contexto seleccionado.
7. Limpiar los filtros para regresar a la vista general.

## Storytelling y análisis

El dashboard fue diseñado para evitar una lectura puramente descriptiva de los datos.

Se realizó primero un **análisis humano** de las visualizaciones. Posteriormente se utilizó **ChatGPT como auditor cognitivo**, solicitando una revisión crítica de las conclusiones mediante un enfoque de “abogado del diablo”.

La revisión contempló:
- posibles sesgos de interpretación;
- diferencia entre correlación y causalidad;
- variables omitidas;
- explicaciones alternativas;
- necesidad de contrastar resultados mediante segmentación.

A partir de esta revisión se refinó la capa narrativa del dashboard.

El detalle completo del proceso y los prompts utilizados se encuentra en el documento:

`Registro_Prompts_IA_BIOQUIM_Valeria_Iglesias.docx`
